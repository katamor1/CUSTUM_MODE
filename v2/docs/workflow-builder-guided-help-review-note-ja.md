# Workflow Builder Guided Help レビュー観点

## 確認観点

- Step type を切り替えたとき、設定ガイドが変わること。
- `steps[].type` の選択肢が説明付きで表示されること。
- `result.source` の選択肢が説明付きで表示されること。
- `result.stateKey` が resultKey と生成元 step 情報付きで表示されること。
- `artifacts.producedBy` が step id / title / type 付きで表示されること。
- Preview / Diagnostics の関連設定リンクから対象タブへ移動できること。
