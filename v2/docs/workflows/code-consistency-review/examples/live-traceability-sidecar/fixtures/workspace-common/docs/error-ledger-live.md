# 課題・エラー台帳 LIVE-001

## ERR_TIMEOUT

ERR_TIMEOUT: タイムアウト時は正常完了ではなく `ERR_TIMEOUT` として呼び出し元へ返す。

## ERR_LIMIT_EXCEEDED

ERR_LIMIT_EXCEEDED: 上限超過時に返すエラーコード。

## ERR_FRAUD_REVIEW

ERR_FRAUD_REVIEW: 不正スコア 80 以上の審査遷移で返すエラーコード。

## QA-QA001-FRAUD-0001 不正スコア確認

QA-QA001-FRAUD-0001: 不正スコアしきい値 80 が今回も承認済みかリスクオーナーへ確認する。
