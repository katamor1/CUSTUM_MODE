## BD-45 timeout 処理方式

RT 側の制御処理で timeout を検出した場合、RT 側はエラーコードを設定し、速やかに上位へ戻る。

RT 側ではファイル出力、重いログ整形、ブロッキング待ちを行わない。

TS 側は、RT 側から通知された timeout 情報を受け取り、詳細ログ保存や保守用情報の整理を行う。

## BD-46 責務分担

| 領域 | 責務 |
|---|---|
| RT | timeout 検出、エラーコード設定、上位通知 |
| TS | 詳細ログ、保守用情報保存、再計算 |
