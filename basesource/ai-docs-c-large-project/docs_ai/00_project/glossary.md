| Core EXE | 起動時にDLLをPEロードする中核EXE | 実ファイル名は後で記入 |

| Module Card | モジュールの役割、依存、共有状態、リスクをまとめたAI向け概要 | docs_ai/50_module_cards |
| AI Packet | AIに渡す調査用コンテキスト一式 | docs_ai/80_ai_packets |
