# プロジェクト概要

## 対象システム

- 言語: C
- ビルド: Visual C++ 6.0 / dsw / dsp
- 規模: 約300MB / 約7000ファイル
- 構成: 2 dsw / 48 dsp
- 成果物: DLL中心
- 起動方式: コアEXEが起動時にDLLをPEロード
- 特徴:
  - 共有ヘッダが複数DLL間の共有メモリIFとして使われる
  - 構造体メンバ単位で1万以上のグローバル変数
  - データ共有・バックアップ系のカーネルモジュールあり

## AIドキュメント整備の目的

AIが調査・設計・テスト支援を行う際に、毎回プロジェクト全体を読ませるのではなく、必要な構成情報、根拠、関連ファイル、共有状態、リスクを小さなコンテキストパケットとして渡せる状態を作る。
