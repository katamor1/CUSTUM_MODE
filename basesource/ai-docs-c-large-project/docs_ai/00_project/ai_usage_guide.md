# AI利用ガイド

## 原則

1. AI生成物は正式仕様ではない。
2. AI生成物には必ず根拠、推定、未確認事項、信頼度を記載する。
3. 信頼度Dの内容は正式ドキュメントへ採用しない。
4. 共有メモリIF、初期化順序、バックアップ・復元、異常時仕様は人間レビュー必須。
5. 古いコメントを事実として扱わず、必ず実装根拠を確認する。

## 信頼度

| 信頼度 | 意味 |
|---|---|
| A | ソース・ビルド定義・複数根拠で確認済み |
| B | ソースから概ね確認済み |
| C | 名前・呼び出し関係からの推定を含む |
| D | AI推定。採用禁止。人間確認待ち |

## AIへの入力単位

- モジュール単位
- 共有ヘッダ単位
- DLL公開関数単位
- 機能フロー単位
- グローバル状態のスライス単位

プロジェクト全体をそのまま投入しない。
