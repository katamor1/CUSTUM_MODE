# AI Docs for Large VC6 C Project

このリポジトリは、大規模C言語プロジェクトに対して、AIが調査・設計・テスト支援を行いやすくするためのドキュメント、プロンプト、コマンド、スクリプト、進捗状態を管理するための作業用リポジトリです。

## 目的

- VC6 `dsw/dsp` 構成をAIが理解できる形に台帳化する
- DLL、共有メモリIF、グローバル変数、バックアップ・復元処理を構造化する
- AI生成ドキュメントを人間レビュー後に正式採用する
- 設計支援、影響調査、テスト設計の材料を蓄積する

## 基本ルール

AIは正式仕様を直接作らない。AIは根拠付きの仕様候補を作る。正式仕様に昇格させるのは人間レビュー後のみ。

## ディレクトリ

```text
docs_ai/       AI向け・人間向けドキュメント
schemas/       JSONスキーマ
prompts/       AI調査・レビュー用プロンプト
commands/      GitHub/ローカル実行コマンド
scripts/       dsw/dsp解析・台帳生成スクリプト
progress/      進捗状態、MVP、レビュー状況
.github/       Issue/PRテンプレート、CI
```

## 最初のMVP

2. DLL出力一覧

4. 共有ヘッダ候補一覧

6. AIレビュー記録テンプレ

## 想定AI

GPT5.5THINKDEEPER などの大規模推論モデルを想定。ただし、AI出力は必ず根拠・推定・未確認事項・信頼度を分離して管理する。
